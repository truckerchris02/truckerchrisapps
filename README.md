# TruckerChris Apps

Download hub for TruckerChris Android apps.

Live page: https://truckerchris02.github.io/truckerchrisapps/

APK and Flatpak files are published as GitHub Release assets. They are not stored in this repository.

## Apps

The download page has two sections. All-in-One Hub Apps come first, then Single Apps. Within each section, apps are listed A to Z. On the page, put a new card in that section’s container (`data-section="all-in-one"` or `data-section="single"`); each container is sorted by app name when the page loads.

## How to install an APK

1. Download the APK from the page or from the GitHub Release.
2. Open the file. If Android blocks it, allow installs from unknown sources for your browser or file manager (Settings → Apps → Special app access → Install unknown apps).
3. Tap Install, then open the app.

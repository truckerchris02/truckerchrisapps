TruckerChris Apps

Android apps by TruckerChris. Each download is a file attached to that app’s GitHub Release.

How to install an APK

  1. Tap Download APK and wait for the file to finish saving.
  2. Open the download. Android blocks apps that did not come from the Play Store until you allow them.
  3. Allow install from unknown sources for your browser or file manager (Settings, then Apps, then Special app access, then Install unknown apps), then tap Install.
